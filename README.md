# 🐱 哈基米造梗机 · 中文互联网抽象热梗构造器

一款基于 **SwiftUI + SwiftData** 打造的原生 macOS 中文互联网抽象热梗构造器。

## ✨ 功能特色

- **🎛️ 造梗工坊**：内置 6 大经典中文互联网抽象流派与 14 套圣经模板：
  - 🐱 哈基米圣经（南北绿豆 / 曼波赛博咏叹调）
  - 🤯 抽象发疯（家人们谁懂啊 / 纯路人锐评 / 阴暗爬行发疯文学）
  - 💼 赛博牛马（大厂黑话 × 牛马破防 / 已老实求放过）
  - 🧠 弱智吧哲学（弱智吧深夜神思考 / 听君一席话废话大师）
  - 📜 经典定型文（你说的对但是…… / 从夯到拉排行榜 / 贴吧六字真言）
  - 😤 回答我咆哮（回答我！Look in my eyes! / 那我问你反杀体）
- **🎚️ 抽象浓度与滤镜调音台**：
  - `0% ~ 100%` 抽象浓度实时调节
  - Emoji 爆浆、谐音黑话加密、括号内心戏、咆哮标点、热搜标签 `#` 一键开关
  - 20 个高频热梗词条快捷加料，支持「摇个大活 (`⌘R`)」与「彻底盲盒」全随机
- **💬 双模式实时预览**：
  - 梗卡片模式（含抽象段位仪表盘、含梗量评分与字数统计）
  - 群聊发癫预览模式（支持自定义群昵称与模拟群友破防回复）
- **📚 抽象热梗词典**：收录 16 个高频抽象热梗的出处、释义与例句，支持检索、复制及一键送入造梗工坊二创
- **⭐ 我的梗库**：基于 SwiftData 本地持久化保存收藏热梗，支持检索、星标过滤、流派筛选与回工坊二创

## 🛠️ 运行环境

- macOS (Xcode / SwiftUI / SwiftData)
- 打开 `hajimitest.xcodeproj`，选择 `hajimitest` Scheme，按 `⌘R` 即可运行。
